# Map Gathering Lists Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The world map's corner gains Herbs and Ore lines and, on a zone's own map, a hoverable icon per gathering line that lists what is found there.

**Architecture:** A browser-read source file and a generator script produce a pure data module (`MapData.lua`). `MapInfo` (pure) turns it into lines and list rows; `MapReadout` draws them and owns the only mouse-live frames; `API` asks the game for the icons.

**Tech Stack:** Lua 5.1 (WoW Forever 16001), Python 3 stdlib for the generator, lupa for the suite.

**Spec:** `docs/superpowers/specs/2026-11-14-map-gathering-lists-design.md`

## Global Constraints

- `API.lua` is the only file that calls Blizzard game APIs, each through `attempt()` / `call()`.
- Pure modules touch no Blizzard global at file load. No libraries. No Blizzard frame templates; colours only from `Look.COLOUR`.
- An unknown answer from the game means do nothing (here: a letter square instead of an icon).
- `GoblinThings/MapData.lua` is generated by `python tools/make_gathering.py`, never hand-edited.
- TOC order becomes `... TrackerSort, MapData, MapInfo, Kills, ...`; `test/run.lua`'s module list matches.
- Suite, luacheck and lua-language-server stay at zero failures and zero warnings.
- Commit after each task: `Area: plain sentence`. No push.

## Review Focus

- A zone with gathering data but a switch off: its line and icon are both gone, and the other lines close up.
- A zone with herbs but no ore (and the reverse): one line, no gap, no empty icon.
- A map `MapData` has never heard of (Mount Hyjal, a city, a continent): exactly today's lines.
- `ns.MapData` missing or a list malformed: `MapInfo` returns today's lines, never an error.
- A hovered zone on a continent: text lines, `icons == false`.

Each is pinned by a test in Task 2.
